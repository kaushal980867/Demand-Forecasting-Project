# Champagne Sales Forecasting Project

## Objective
Forecast monthly champagne sales to support business planning, budgeting and inventory control.

## Models Used
- ARIMA (1,1,1)
- SARIMAX (1,1,1)(1,1,1,12)
- Prophet
- AutoRegression

## Key Findings
SARIMAX performed best because the data shows strong yearly seasonality patterns.

## How to Run
```
streamlit run app.py
```
